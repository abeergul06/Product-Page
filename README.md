ShopEase – Component-Based Product Page

A modern and responsive product shopping page built using HTML, CSS, and JavaScript. The project demonstrates a component-based frontend approach with reusable product cards, product filtering, and client-side cart state management.

Technologies Used
Technology	  Purpose
HTML5	        Page structure
CSS3	        Styling and responsive design
JavaScript  	Components, filtering, and cart state
Unsplash    	Product images
